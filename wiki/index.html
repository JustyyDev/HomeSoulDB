SoulScorch Engine

Homebrew wiki, mod registry, and HomeSoul Cove control deck.

This repo can now power both the public documentation on soulscorch.org and the always-on Cloudflare API behind HomeSoul Cove.

Read the wiki Deploy on Cloudflare

Engine

Build actual games on the FNF base.

SoulScorch is documented as an engine, not only a mod runtime. The wiki is structured around engine setup, 3D systems, scripting, packaging, and mod jams.

Marketplace

HomeSoulDB powers the catalog.

Catalog entries can advertise billboard text, jam support, chat compatibility, and avatar showcase metadata for HomeSoul Cove stands.

Cloudflare

Worker API keeps the Cove online.

The Worker exposes realtime-friendly HTTP endpoints for plaza presence, stands, chat, and voice-room signaling metadata without requiring your desktop to stay on.

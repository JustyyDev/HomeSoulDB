HomeSoul Cove

A 3D showcase plaza where projects, players, and jams can meet.

HomeSoul Cove is the social-facing layer of the SoulScorch ecosystem. It is where a user can enter the engine, generate a simple identity, claim a stand, advertise a project, and browse what other people are building.

Current prototype scope

Profiles Stands Billboards Text chat Voice room metadata

Cove pitch: it is the part of SoulScorch that makes projects feel inhabited, discoverable, and event-ready.

What the Cove is for

Project discovery

Creators can pitch a game or mod inside a shared 3D environment instead of relying only on social posts and repository links.

Community presence

The Cove gives SoulScorch a public social shell where showcases, testing sessions, and jam floors can live.

Event presentation

Jams can use booth rotations, event rosters, short billboard text, and voice-room contracts to make exhibitions feel organized.

Core runtime flow

Entry

First visit asks for a username and a body type. The engine stores that locally and generates a base avatar.

Exploration

Players move through the plaza with mouse look and keyboard movement while discovering open or claimed stands.

Stand claim

A creator claims a stand, writes short billboard copy, and stores a HomeSoulDB-ready submission draft in-engine.

Sync

The Cove service syncs presence, stand leases, and chat metadata toward the online API when configured.

API routes

HomeSoul Cove is built around movement, identity, stands, social presence, and project discovery. For visitors, the important part is not the backend shape. The important part is how a project feels when it is presented inside the Cove.

Cloudflare Deploy

Use one repo for the wiki and the Cove API.

Cloudflare Pages

Create a Pages project from this repo and set the output directory to `wiki`. Bind it to `www.soulscorch.org`.

Cloudflare Worker

Deploy `worker/index.js` with Wrangler. Bind the Worker to `api.soulscorch.org` and configure D1 plus KV with the IDs in `wrangler.toml`.

GitHub Actions

Keep Actions for validation and registry publishing only. Do not use it as the live multiplayer host.

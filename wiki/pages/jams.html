Jam Roster

Game jams and mod jams should feel like part of the site, not an afterthought.

This page is the public event roster for SoulScorch. It can act as the visible schedule while HomeSoul Cove uses stands and API metadata to represent those same events in-engine.

How to use this page

Keep one active jam, one upcoming jam, and one archive highlight visible at a time. That keeps the page readable while still making the community feel active.

Roster fields you should keep updated

  • Jam name and short theme line
  • Kickoff and deadline dates
  • Whether the event is for mods, full games, or both
  • Whether HomeSoul Cove booths will be used
  • Any restrictions on team size, runtime target, or content rating

Getting Started

Set up SoulScorch as an engine.

1. Clone the engine

Keep the engine repo and HomeSoulDB side by side so catalog changes, plaza runtime work, and Cloudflare deployment can evolve together.

2. Use HomeSoulDB for the online layer

Catalog validation lives in GitHub Actions. The Worker API hosts HomeSoul Cove state. The wiki explains both from the same repo.

3. Point the engine to the API

Set the engine's Cove API base URL to `https://api.soulscorch.org` once the Worker is deployed.
